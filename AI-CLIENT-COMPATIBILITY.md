# AI client compatibility

The canonical shared skills live in `.agents/skills/`. Current agent tools that support this layout include Claude Code, Codex/OpenAI agent workflows, and Qwen Code. The project also includes `CLAUDE.md`, `AGENTS.md`, and `QWEN.md` for host-specific context.

Qwen Code supports project skills from `.agents/skills/` and `.qwen/skills/`; its documented shared-skills guidance recommends `.agents/skills/` for Claude Code, Codex, and Qwen Code. OpenAI/Codex can additionally use `.codex/skills/`.
